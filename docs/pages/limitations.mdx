# Limitations

## Image Constraints

| Constraint | Value |
|---|---|
| Minimum image size | 64 × 64 pixels |
| Maximum image size | 8192 × 8192 pixels |
| Undo steps | 20, within a 1.5 GB memory budget |
| Recent files | 10 |

## Platform

- **Windows is the supported platform.** The code is cross-platform, but only Windows builds are produced and tested.

## Theme

- **One dark theme.** There is no light mode.

## Previews and the GPU

- **Export always uses the CPU.** The GPU draws the live previews only; tests hold the two within one 8-bit step.
- **Splat synthesis and delighting are previewed on the CPU.** So are images beyond the GPU's texture limit and machines without a usable GPU. Help › About shows which is in use.
- **No NVIDIA-only acceleration.** The CUDA path of the earlier Python version is gone; Splat runs on all CPU cores.

## Splat Synthesis

- **The seed is a control**, set with the Shuffle button. The same input, settings and seed always give the same result.

## Material Maps

- **Maps are derived from the seamless base color** through a height field chosen by *Height source*. A generated map cannot be run through a seamless method on its own.

## Export

- **No material scripts.** SEAMS writes texture files only.
- **Scalar maps are single-channel** unless the source has alpha.
- **Resizing is not applied on export.** The result keeps its size.
- **JPEG drops alpha.**

## Delight

- **Applying is destructive**, though undoable. After applying, the sliders reset to 0.

## Crop, Retouch and Check

- **Perspective crop samples bilinearly**, so a heavily straightened result is slightly softer than the source.
- **A turned or perspective crop repeats edge pixels** where it reaches past the image.
- **The tiling check works on a small grey copy**, so it finds visible seams and strong repeats, not fine detail.

## Drag & Drop

- **Only PNG, JPG, TIFF, TGA and EXR files** open. Other files are rejected with a message.

## Float Images

- **NaN and infinite values are replaced** on load (NaN with 0, infinities with the ends of the range) without a warning.
