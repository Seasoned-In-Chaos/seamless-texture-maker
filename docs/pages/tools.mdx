# Crop, Retouch and Check

These tools work on the base color. Each is one undo step.

## Crop (`C`)

A frame that you move, resize and turn over the image, as in Photoshop's Classic mode.

| Gesture | Action |
|---|---|
| Drag inside the untouched frame | Draw a new frame (`Shift`: square, `Alt`: from the centre) |
| Drag inside the frame | Move it |
| Drag an edge or corner | Resize (`Shift`: keep proportions, `Alt`: about the centre) |
| Drag outside the frame | Turn it (`Shift`: 15° steps) |
| `Enter` / `Esc` | Apply / cancel |

The inspector sets an aspect ratio (free, original, 1:1, 4:3, 3:4, 16:9, 9:16, 2:1), the exact size and the angle. An upright crop copies pixels exactly. A turned one is resampled and repeats edge pixels where it reaches past the image.

### Perspective Crop (`Shift+C`)

For a photo of a wall, floor or sheet shot at an angle. Drag each corner onto a corner of the surface and apply: the four-cornered region is straightened into a rectangle. Drag an edge to move both its corners, or the inside to move the whole shape. The grid follows the perspective, and a move that would fold the shape inward is refused. The result size is measured from the edges unless you set it.

## Retouch (`J`)

Photoshop's Clone Stamp, Healing Brush and Spot Healing Brush, for painting out seams and blemishes.

1. For **Heal** and **Clone**, **Alt-click** where to copy from. Before you paint, the brush shows the source inside its circle.
2. Paint. **Spot heal** needs no source: paint over the blemish.

| Mode | What it does |
|---|---|
| **Heal** | Copies the source's detail. When you release, the whole stroke is matched to the color and brightness where it landed, with no seams between dabs |
| **Clone** | Copies pixels exactly |
| **Spot heal** | Fills the stroke from what surrounds it: **Content-aware** rebuilds it patch by patch, **Proximity** copies the best-matching nearby area |

Healing runs in the background after you release; the stroke shows as a clone (or, for Spot heal, a dark mark) until it finishes. Each stroke is one undo step.

### Brush

| Setting | What it does |
|---|---|
| **Size** | Diameter in image pixels |
| **Hardness** | 100 % is a hard edge; lower is softer. The inner ring of the cursor shows the hard core |
| **Opacity** | The most a stroke covers |
| **Flow** | How much each dab adds: low flow builds up gradually under the opacity cap |
| **Spacing** | Distance between dabs, as a share of the diameter |
| **Smoothing** | Steadies a shaky line: the brush trails the pointer and catches up |

**Aligned** keeps the distance between brush and source from stroke to stroke; off, every stroke starts from the source point again. With **Wrap around edges** on, strokes and the source continue across the edges, so a tileable texture stays tileable. In the **Tiled** view you can paint over the tile borders. The options are remembered.

| Key | Does |
|---|---|
| `[` / `]` | Smaller / larger brush |
| `Shift+[` / `Shift+]` | Softer / harder |
| `1` … `0` | Opacity 10 % … 100 % |
| `Shift+1` … `Shift+0` | Flow 10 % … 100 % |
| `Alt`+right-drag | On the canvas: sideways sets the size, up and down the hardness |

### Fixing seams a method left

In the Seamless stage, click **Use result as base** (or Edit › Use result as base). The result becomes the base color and the method becomes **None (already tiles)**, so it is not processed again. Then retouch the seams directly.

## Check Tiling (`Ctrl+Shift+T`)

Marks what spoils tiling, on the canvas and on every tile in the tiled view:

- **Red** lines are seams, including the line where the texture wraps from one edge to the other.
- **Orange** areas repeat elsewhere in the texture.

The inspector summarizes both, for example "Visible seam where the texture wraps" or "Repeats 90% alike at a shift of +50% across". The check works on a small grey copy, so it finds visible seams and strong repeats, not fine detail.
