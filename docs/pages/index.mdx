## Features

<CardGroup cols={3}>
  <Card title="Delighting" icon="sun" href="/pages/delight">
    Remove baked-in shadows, highlights and lighting gradients to get a flat base color.
  </Card>
  <Card title="Seamless Processing" icon="repeat" href="/pages/seamless/overlap-blend">
    Offset cross-fade, mirror tiling, overlap blend or splat synthesis, with live previews.
  </Card>
  <Card title="Material Maps" icon="palette" href="/pages/material-lab">
    Normal, roughness, ambient occlusion, displacement and opacity maps from the base color.
  </Card>
  <Card title="Crop and Perspective Crop" icon="crop" href="/pages/tools">
    Crop with a turnable frame, or straighten a photo of a surface shot at an angle.
  </Card>
  <Card title="Clone and Heal" icon="bandage" href="/pages/tools">
    Paint out seams and blemishes. Strokes wrap across the edges, so the texture keeps tiling.
  </Card>

  </Card>

## Why SEAMS?

- **Native and small.** One executable of about 20 MB. Nothing to install first.
- **Live.** Sliders update the result as you drag. On a capable GPU the maps and the seamless result are previewed at full resolution.
- **Honest output.** Export always uses the CPU code, and tests hold the GPU preview within one 8-bit step of it.
- **Safe.** Every action is undoable, and a failure is reported in the status bar instead of closing the window.

## System Requirements

| Requirement | Minimum | Recommended |
|---|---|---|
| **OS** | Windows 10 (64-bit) | Windows 11 |
| **RAM** | 8 GB | 16 GB or more for 4K textures |
| **Graphics** | DirectX 12, Vulkan or OpenGL | A dedicated GPU |
| **Disk** | 50 MB | 50 MB |

<Note>
A GPU is optional. Without a usable one, previews run on the CPU and nothing else changes. Set `SEAMS_CPU_PREVIEW=1` to force the CPU.
</Note>
