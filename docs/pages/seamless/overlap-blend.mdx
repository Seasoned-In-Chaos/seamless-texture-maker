# Overlap Blend

The Overlap Blend method creates seamless textures by overlapping the far edge of the image onto the near edge, joining the two around the middle of the overlap strip, then cropping the consumed strip and resizing back to the original dimensions. The transition at that join is deliberately kept narrow — a transition spanning the whole strip would leave a wide band sitting near a 50/50 mix, which visibly double-exposes ("ghosts") strong non-repeating features like faces, logos, or distinct objects.

<Tip>
Overlap Blend is best for architectural textures, fabrics, and any image with regular patterns that need clean tiling.
</Tip>

## Technique Selection

In the Seamless panel, set the **Method** dropdown to **Overlap Blend**.

### Material Presets

| Preset | Description |
|---|---|
| **Stone** | Balanced settings for rocky surfaces |
| **Fabric** | Tighter overlap for woven materials |
| **Organic** | Softer falloff for natural surfaces |
| **Hard Surface** | Sharper blending for man-made materials |

## Controls

| Slider | Range | Default | Description |
|---|---|---|---|
| Overlap X | 0–50% | 0% | Horizontal overlap blend width as a percentage of image width |
| Overlap Y | 0–50% | 0% | Vertical overlap blend width as a percentage of image height |
| Edge Falloff | 0–100% | 0% | Softness of the join only. **0% = a hard, unblended seam** (not "no effect" — Overlap X/Y still apply); 100% = the widest permitted soft gradient |

<Note>
Overlap X/Y replace image content, so they always change the result — the live preview responds to them at any Edge Falloff, including 0%. Edge Falloff controls only how soft the join looks.
</Note>

### How It Works

1. **Overlap** — The far-edge strip (width = `overlap_x` × image width) is overlapped onto the near-edge strip. The leading portion is a solid copy of the far edge — that copied run *is* the overlap, and it's what makes the tile wrap. Likewise bottom onto top for `overlap_y`
2. **Join at the midpoint** — Around the middle of the strip the image switches back to its original content. At Edge Falloff 0% this is a hard step (half the strip is a solid copy, exactly like a plain cut); raising falloff eases the switch across a wider span
3. **Transition is capped** — It never spans more than half the overlap strip, and uses a double-smoothstep curve so the near-50/50 zone stays narrow. This is what prevents ghosting at high falloff
4. **Crop** — The consumed strip is cropped off and the image is resized back to its original dimensions

### Blend Width

The actual blend width in pixels is:

```
blend_width = image_width × overlap_x   (horizontal)
blend_width = image_height × overlap_y  (vertical)
```

For a 2048×2048 image at 20% overlap, that's a 410-pixel blend strip on each axis.

## Chunked Processing

For images larger than 2048px, SEAMS automatically:

1. Splits the image into 1024×1024 tiles with 64px overlap
2. Processes each tile independently
3. Reassembles with linear gradient blending at tile boundaries
4. Applies 2D corner fade: `fade = fade_y × fade_x` to eliminate corner artifacts

<Note>
Chunked processing runs automatically — there are no user controls for tile size or overlap. It triggers for any image where `max(width, height) > 2048`.
</Note>

## Live Preview

As you adjust sliders, SEAMS runs a 3-stage progressive preview:

| Stage | Trigger | Scale | Quality |
|---|---|---|---|
| Stage 1 | Immediate (0ms) | 12.5% | Rough instant feedback |
| Stage 2 | 80ms debounce | 50% | Medium quality |
| Stage 3 | 400ms debounce | 100% | Full resolution |

Results are cached — changing a slider back to a previous value returns instantly from the LRU cache (up to 50 entries).
