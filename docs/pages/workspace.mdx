# Workspace

SEAMS has one window with five areas: the top bar, the canvas, the inspector, the map strip and the status bar. Until a texture is open, only the top bar and the canvas are shown.

## Top Bar

The menus are on the left. The workflow stage is in the middle: **Delight**, **Seamless** and **Material**, also `1`, `2`, `3`.

## View Bar

The view bar floats over the bottom of the canvas.

| Control | Purpose |
|---|---|
| **Result / Split / Side by side / Tiled** | How the canvas presents the image. |
| **Tile count and Guides** | Shown in the tiled view: 2 x 2 to 4 x 4, and lines where tiles meet. |
| **Crop, Retouch, Check tiling** | The image tools (`C`, `J`, `Ctrl+Shift+T`). See [Crop, Retouch and Check](/pages/tools). |
| **Pan, Zoom, Fit** | The pan tool (`H`), the zoom tool (`Z`) and fit to the window (`Ctrl+0`). |
| **− / percentage / +** | Step the zoom out and in; click the percentage for actual size (`Ctrl+1`). |

## Canvas

| Gesture | Action |
|---|---|
| Scroll | Zoom about the pointer |
| Middle-button drag, or drag with the pan tool (`H`) or `Space` held | Pan |
| Double-click | Fit to window |
| Drag the divider | Move the split, in the split view |

The split and side-by-side views compare the base colour before and after processing. They apply to the base colour; a generated map is always shown on its own.

Entering the Delight stage switches to the side-by-side view, because delighting is judged against the original.

## Inspector (right)

The inspector shows the settings of the current stage.

| Stage | Settings | Actions |
|---|---|---|
| Delight | Preset, eight adjustments, reset | Apply delight |
| Seamless | Method, material preset, the method's settings | - |
| Material | Height source, then the settings of the selected map | - |

In the Material stage, selecting a map in the map strip shows only that map's settings. Selecting the base colour shows them all.

Export is pinned to the bottom of the inspector: the file format and a button that exports whatever is selected in the map strip. Whether a quick save (`Ctrl+S`) writes a new file or replaces the original is set in the File menu.

## Map Strip (below the canvas)

One thumbnail each for the base colour, normal, roughness, AO, displacement and opacity. Click a thumbnail to show it on the canvas and make it the export target.

## Status Bar

- **Left:** the file name, dimensions, bit depth and file size.
- **Right:** the latest message, and what is running in the background (opening, rendering, generating maps, saving).

Errors appear here in red and stay for twelve seconds. Nothing interrupts you with a dialog, except the confirmation before a quick save replaces the original file.

### File

|---|---|

| Item | Shortcut |
|---|---|
