# Getting Started

## System Requirements

| Requirement | Minimum | Recommended |
|---|---|---|
| **Operating System** | Windows 10 (64-bit) | Windows 11 |
| **RAM** | 8 GB | 16 GB or more for 4K textures |
| **Graphics** | DirectX 12, Vulkan or OpenGL | A dedicated GPU |
| **Disk Space** | 50 MB | 50 MB |

SEAMS is a single native executable. It needs no runtime, and nothing else has to be installed.

## Installation

### Pre-built Installer

Download the latest installer from the [GitHub Releases](https://github.com/Seasoned-In-Chaos/seamless-texture-maker/releases) page, run it and follow the prompts. The standalone `SEAMS.exe` on the same page runs without installing.

### From Source

Install [Rust](https://rustup.rs) 1.90 or newer. With the GNU toolchain, also install MinGW-w64 (`winget install BrechtSanders.WinLibs.POSIX.UCRT`). With the MSVC toolchain, install the Visual Studio C++ build tools instead.

```bash
git clone https://github.com/Seasoned-In-Chaos/seamless-texture-maker.git
cd seamless-texture-maker

cargo run --release -p seams
```

## First Launch

The window opens on an empty canvas with an **Open texture** button. Open a file with it, with `Ctrl+O`, by double-clicking the canvas, or by dropping an image on the window. You can also pass a file on the command line or use **Open with** in Explorer.

Supported formats are PNG, JPG, TIFF, TGA, EXR and Photoshop PSD (PSB files open too). Images must be between 64 and 8192 pixels on each side.

## Settings and Logs

Settings are stored in:

```
%APPDATA%\SeamlessTextureMaker\settings.json
```

The log is at:

```
%APPDATA%\SeamlessTextureMaker\logs\seams.log
```

A missing or unreadable settings file is ignored: SEAMS starts with defaults. Delete the file while SEAMS is closed to reset everything.

## Building the Installer

`build.bat` runs the complete production build:

```batch
build.bat
```

It:

1. Finds the Rust toolchain
2. Runs the test suite, and stops if a test fails
3. Builds the release executable to `dist\SEAMS.exe`
4. Signs it, if `SIGN_PFX` is set
5. Builds the Inno Setup installer, if Inno Setup is installed

For a Microsoft Store (MSIX) package, use `build_store.bat`. It needs the Windows 10 SDK.
