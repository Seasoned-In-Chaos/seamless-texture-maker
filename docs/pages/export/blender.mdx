# Blender Export

SEAMS exports textures optimized for Blender's Principled BSDF with OpenGL normal convention. It writes texture maps only; material nodes are configured in Blender.

## Blender Default Settings

| Setting | Value |
|---|---|
| Workflow | Roughness |
| Normal Format | OpenGL (Y+) |
| Format | PNG |
| Bit Depth | 16-bit |
| Output | Texture maps only |

## File Naming

```
MaterialName_BLENDER_BaseColor.png
MaterialName_BLENDER_Normal.png
MaterialName_BLENDER_Roughness.png
MaterialName_BLENDER_AO.png
MaterialName_BLENDER_Displacement.png
```

## Tips for Blender

- Import textures as **Non-Color** (for Normal, Roughness, AO, Displacement) or **sRGB** (for BaseColor)
- Enable **Displacement** in the material settings when using displacement with Cycles
- For Eevee, configure a bump or displacement node manually as required by the material
