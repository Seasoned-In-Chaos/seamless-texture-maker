# Blender

SEAMS does not currently include a Blender-specific export preset. Export the individual maps from [PBR Export](/pages/export/pbr-export) and wire them into your material's Principled BSDF node in Blender.

<Tip>
Blender's Normal Map node expects OpenGL-convention (Y+) normal maps — the default in Material Lab's Normal controls.
</Tip>
