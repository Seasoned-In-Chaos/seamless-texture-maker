# Unreal Engine 5

SEAMS does not currently include a UE5-specific export preset or automatic ORM (AO/Roughness/Metallic) packing. Export the individual maps from [PBR Export](/pages/export/pbr-export) and pack/configure them in UE5's material editor.

<Tip>
UE5 expects DirectX-convention (Y-) normal maps. Set this in Material Lab's Normal controls before exporting the Normal map.
</Tip>
