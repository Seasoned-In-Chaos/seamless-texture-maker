# PBR Export

SEAMS exports texture maps directly from the toolbar and keyboard shortcuts below — there is no separate export dialog or renderer-preset system.

## Export Paths

| Action | Shortcut | What it does |
|---|---|---|
| Save Current Texture | `Ctrl+S` | Saves the processed seamless texture |
| Save As... | `Ctrl+Shift+S` | Saves to a chosen path and format |
| Export Selected Map | `Ctrl+E` | Saves the currently active channel (Base Color, Normal, Roughness, AO, Displacement, or Opacity), generating it first if needed |
| Quick Export button | — | Uses the Format and Save Mode set in the control panel |

See [Quick Export](/pages/export/quick-export) for format, compression, DPI, and file-naming details.

## Renderer Workflows

SEAMS does not apply renderer-specific presets (ORM packing, glossiness conversion, per-renderer naming) automatically. Export the individual maps above and configure color space, texture packing, and compression in your target application.

The Normal map's orientation (OpenGL Y+ vs. DirectX Y-) is set in Material Lab's Normal controls at generation time — pick the convention your target renderer expects before exporting.
