# V-Ray

SEAMS does not currently include a V-Ray-specific export preset. Export the individual maps from [PBR Export](/pages/export/pbr-export) and wire them into a VRayMtl in your scene.

<Tip>
V-Ray expects DirectX-convention (Y-) normal maps. Set this in Material Lab's Normal controls before exporting the Normal map.
</Tip>
