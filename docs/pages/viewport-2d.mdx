# Canvas

The canvas is where you view and compare your textures.

## Opening an Image

- **File dialog**: `Ctrl+O`, or File › Open texture
- **Drag and drop**: drop a PNG, JPG, TIFF, TGA or EXR file on the window
- **Double-click** the empty canvas

## View Modes

| Mode | Description |
|---|---|
| **Result** | The processed result alone |
| **Split** | A draggable divider with the original on the left and the result on the right |
| **Side by side** | The original and the result next to each other |
| **Tiled** | The result repeated 2 × 2, 3 × 3 or 4 × 4, to check that it tiles |

Switch modes in the view bar over the canvas. In the tiled view, **Guides** draws dashed lines where tiles meet.

## Zoom and Pan

| Action | Control |
|---|---|
| Zoom | Scroll wheel, 10% per notch, about the pointer |
| Zoom in / out | `Ctrl+=` / `Ctrl+-`, or the + and − buttons, through Photoshop's zoom levels |
| Zoom tool | `Z`: click to zoom in, `Alt`-click to zoom out, drag right or left to zoom |
| Pan | Middle-button drag, or left drag with the pan tool (`H`) or `Space` held |
| Scroll sideways / up and down | `Shift` / `Alt` + scroll |
| Fit to window | `Ctrl+0`, the Fit button, or a double-click |
| Actual size | `Ctrl+1`, or click the zoom percentage |

The image cannot be panned out of sight: a large image stops at its edges, and a small one stays inside the window.

## Map Strip

The strip under the canvas has a thumbnail for the base color and each map. Click one to show it on the canvas and make it the export target.

## Undo and Redo

| Action | Shortcut |
|---|---|
| Undo | `Ctrl+Z` |
| Redo | `Ctrl+Shift+Z` or `Ctrl+Y` |

Up to 20 steps. Applying delight, a crop, a retouch stroke or **Use result as base** each makes one step.
