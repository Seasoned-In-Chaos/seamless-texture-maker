# Settings

SEAMS saves your settings when you close it, in:

```
%APPDATA%\SeamlessTextureMaker\settings.json
```

## What Is Saved

| Key | Description |
|---|---|
| `params` | The Delight, Seamless and Material settings |
| `stage` | The last workflow stage |
| `export_format` | The export format |
| `save_mode` | `new_file` or `overwrite`: what a quick save does |
| `last_directory` | The folder of the last opened file |
| `recent_files` | Up to 10 recently opened files |
| `view` | The tiled view's tile count and whether guides are shown |
| `window` | The window size and whether it was maximized |

Unknown or missing keys are ignored, and out-of-range values are clamped. A damaged file is ignored and the defaults are used, so it can never stop SEAMS from starting.

## Reset

Close SEAMS and delete `settings.json`. A new one is made on exit.

## Logs

```
%APPDATA%\SeamlessTextureMaker\logs\seams.log
```
